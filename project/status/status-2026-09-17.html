1What it does

A tool to generate minimalist, print-quality city map posters. Give it a city and country, it fetches OpenStreetMap road/water/parks data via OSMnx, renders it with matplotlib using a chosen colour theme, and saves a PNG (SVG/PDF via --format). Supports 17 built-in themes, multilingual city labels (Japanese, Arabic, Thai, etc.), custom coordinates, and configurable size. Output goes to posters/ named {city}_{theme}_{timestamp}.png.

2How to generate a poster

Single poster (default terracotta theme)

uv run ./create_map_poster.py --city "Edmonton" --country "Canada"

With a specific theme

uv run ./create_map_poster.py --city "Paris" --country "France" --theme noir --distance 10000

All 17 themes at once (comparison)

uv run ./create_map_poster.py --city "Tokyo" --country "Japan" --all-themes

List available themes

uv run ./create_map_poster.py --list-themes

Custom size (A4 print)

uv run ./create_map_poster.py --city "Venice" --country "Italy" --theme blueprint -W 8.3 -H 11.7

Ambiguous location — override coordinates

uv run ./create_map_poster.py --city "Stanley Park" --country "Canada" -lat 49.3043 -long -123.1443 --theme forest

Multilingual labels

uv run ./create_map_poster.py --city "Tokyo" --country "Japan" --display-city "東京" --display-country "日本" --font-family "Noto Sans JP" --theme japanese_ink

6Gotchas

Requires internetNominatim (geocoding) and OSMnx (road data) both hit the internet on each run. No offline mode.
Large distance = slow--distance 20000 fetches a lot of OSM data. For quick previews use a smaller distance or small -W/-H — DPI is hardcoded at 300 (no CLI flag).
Ambiguous citiesSmall towns or landmarks may not geocode correctly. Use --latitude/--longitude to override.
posters/ is NOT gitignoredgit check-ignore finds no rule. Don’t commit experiments — add posters/* to .gitignore (per AGENTS.md).
Nominatim rate limitsRunning --all-themes across several cities in a loop — add delays to avoid rate-limiting.
README image link brokenREADME references posters/edmonton.png, which isn’t in the repo.
