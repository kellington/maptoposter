3 What It Does

A tool to generate minimalist, print-quality city map posters. Give it a city and country, it fetches OpenStreetMap road, water, and parks data via OSMnx, renders it with matplotlib using a chosen colour theme, and saves a PNG. Supports 17 built-in themes, multilingual city labels (Japanese, Arabic, Thai, Korean, etc.), custom coordinate overrides, and configurable size and resolution. Output lands in posters/ named {city}_{theme}_{timestamp}.png. The rendering pipeline is: CLI → Nominatim geocoding → OSMnx data fetch → matplotlib layers → PNG.

4 How to Generate a Poster

This is the most useful section — all commands are copy-paste ready.

Default theme (terracotta)

# Edmonton with default theme uv run ./create_map_poster.py --city "Edmonton" --country "Canada"

Specific theme + distance

uv run ./create_map_poster.py --city "Paris" --country "France" --theme noir --distance 10000

All 17 themes at once (comparison sheet)

uv run ./create_map_poster.py --city "Tokyo" --country "Japan" --all-themes

List available themes

uv run ./create_map_poster.py --list-themes

Custom size (A4 print)

uv run ./create_map_poster.py --city "Venice" --country "Italy" --theme blueprint -W 8.3 -H 11.7

Override coordinates (ambiguous location)

uv run ./create_map_poster.py --city "Stanley Park" --country "Canada" \ -lat 49.3043 -long -123.1443 --theme forest

Multilingual labels

uv run ./create_map_poster.py --city "Tokyo" --country "Japan" \ --display-city "東京" --display-country "日本" \ --font-family "Noto Sans JP" --theme japanese_ink

Quick preview (150 DPI, faster)

# No DPI flag in CLI — reduce --distance instead for speed uv run ./create_map_poster.py --city "Vancouver" --country "Canada" -d 8000

8 Gotchas

Requires internet. Nominatim (geocoding) and OSMnx (road data) both hit the network on every run. No offline mode.
Large distance = slow. --distance 20000 fetches a lot of OSM data. For quick previews, reduce distance rather than expecting a fast render.
Ambiguous cities. Small towns, parks, and landmarks may not geocode correctly. Use --latitude / --longitude to override the centre point.
Posters aren't committed. posters/ is gitignored — regenerate from the CLI when you need them again.
Nominatim rate limits. Running --all-themes on multiple cities in a tight loop can hit rate limits. Add short delays between runs.
First run is slower. uv run creates a virtual environment and installs dependencies on first execution. Subsequent runs are fast.
